How this lending model works

This is a hypothetical single-collateral loan based on Aave v3 collateral concepts. The rates, maximum LTV and liquidation threshold are editable teaching assumptions, not verified current Ethereum market parameters. No wallet or live lending data is used.

ETH represents supplied WETH, with wrapping costs excluded. USDC is fixed at $1. Borrowed USDC stays in the wallet without earning interest; it is not spent or reinvested. Supply interest increases ETH, and borrow interest increases USDC debt.

Both rates use simple interest: starting token amount × APR × days / 365. This keeps the lesson transparent; it does not reproduce Aave’s reserve indexes, variable rates, compounding or exact contract rounding.

Health factor = collateral value × liquidation threshold / debt value. Below 1, the position is eligible for liquidation. With no debt, there is no loan liquidation boundary. Initial borrowing is limited by maximum LTV; later price and interest changes may move a loan above that ratio.

Each result is an endpoint before liquidation. The model does not reconstruct the intervening path or execute a liquidation. It excludes oracle delays, market liquidity, caps, E-mode, additional assets and transaction costs. Inspect currently contains liquidity records; independently verified lending records are a later step.
